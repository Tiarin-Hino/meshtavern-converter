# The name (#147)

Status: picked by the PM, checked against the registers, cased PolyWash (section 4) · Date: 2026-10-14 · Spec: `docs/specs/look-and-feel.md`, L5 · Issue: #147

The page's product name replaces the development name "MeshTavern Converter" wherever a person sees it. The PM picks the name; this file records the pick and the check behind it. The mark made from the name has its own record beside this one.

## 1. The pick

**PolyWash**, picked by the PM on 2026-10-14 after three rounds of candidates (Claude, Argon and ChatGPT); the rounds and the names dropped are in [the issue's comment](https://github.com/Tiarin-Hino/meshtavern-converter/issues/147).

"Poly" is the polygon mesh; "wash" is the hobby's wash and the look the converter gives a mini, primed and washed. Against the checklist of L5: it says what the thing does, it reads as a tool's name on its own, it is spellable after hearing it once, and nothing in the miniature hobby, 3D printing, VTT or 3D software space carries it (section 2).

## 2. The check

Run on 2026-10-14. The web sweep was done in a cloud session before the pick; the registers, the domains and the stores were checked afterwards from the development PC, where those sites answer. These are searches of public databases, not a lawyer's clearance opinion.

### 2.4 Names nearby

Not clashes, but names a reader may set beside this one:

- **Polybrush**, Unity's package for painting and sculpting meshes inside the Unity editor: the same "Poly" + a painting word, in mesh painting. Not a registered US mark in class 9 (the only US POLYBRUSH and POLY-BRUSH records are a dead class 26 mark of a hair-products company and a live class 16 mark of Jen Mfg., Inc.). A different audience (game developers inside Unity), but the closest name in the space.
- **Polycam**, a 3D-scanning app. "Poly" is a common prefix in 3D (Polycam, Poly Haven, Google's former Poly), which makes PolyWash sound at home in the space and makes the second half, "wash", the part that has to carry it.
- **Mini Paint Oh**, a free browser tool for painting miniatures with a wash mode: a neighbour product, not a name clash.

## 3. Fallbacks

If the name has to be given up later, the order of the issue's comment stands: FigureMint, Whittle, MeshTavern Porch, Glazebox, TableReady. None was run through the registers of section 2.1.

## 4. Decided after the check (PM, 2026-10-14)

- **Casing: PolyWash**, with a capital W: the two halves, the polygon and the wash, stay visible. Everywhere a person sees the name it is written this way; the registers and stores above were searched without regard to case.
- **The favicon's short form: "P".** Until the mark is traced, the favicon is the P set in the display face, as spec L2 allows for the placeholder.
- **The domain is registered later**, by the PM, with #47. Nothing was registered by this check: no domain, no GitHub organisation, no npm name.

## 5. Still the PM's

- **The byline** "by MeshTavern" as the app bar's one link (spec L2): its words and target.
- **The address** (#47): the GitHub Pages default path carries the development name (`meshtavern-converter`); a custom domain from section 2.2 or a renamed repository would change it.
